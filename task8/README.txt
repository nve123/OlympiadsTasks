Сегодияшний контест проходит по правилам IOICPC, объединяющим правила IOI и правила
ICPC. В этих правилах у задачи может быть от 1 до 3 подзадач, каждая задача стоит 60 баллов.
баллы за все подзадачи одной задачи равны (то есть задача с одной подзадачей - обычно самая
лёгкая в туре - стоит 60 баллов, в задаче с двумя подзадачами одна подзадача стоит 30 баллов,
в задачах с тремя - по 20 баллов). В случае изменения баллов по задаче на частичный балл к
штрафному времени добавляется соответствующая доля штрафа в ICPC (включая время и штраф-
ные попытки).
Результат участника определяется суммой баллов по всем задачам и суммарным штрафным
временем по всем задачам, округлённым до минут. Участники сортируются по убыванию суммы
баллов, а при равенстве - по возрастанию суммарного штрафного времени. Желающие более по-
дробно ознакомиться с правилами могут пайти их полный вариант в задаче Н текущего тура.
При решении задач по этим правилам важно набирать баллы, решая самые простые подзадачи
(они есть везде, где задача не является совсем тривиальной). Вам даётся 13 целых чисел от 1 до 3 -
количество подзадач в каждой задаче контеста. Ваша задача - найти количество баллов, которое
можно получить, если сдать одну подзадачу в каждой задаче.
Формат входных данных
Входные данные содержат 13 строк. 1-я из этих строк содержит количество подзадач в задаче і
тyра s; (1 <s, <3).
Формат выходных данных
Выведите одно целое число - количество баллов, которое можно получить, если сдать одну
подгруппу в каждой задаче.
Система оценки
Задача состоит из двух подзадач.,
· Подзадача 1 (30 баллов): все s, равны
• Подзадача 2 (30 баллов): Без дополнительных ограничений, необходимые подзадачи - 1
